# API Routes Documentation
# Base URL: http://localhost:8085
# All routes except /auth/* require JWT token in Authorization header: Bearer <token>

## Authentication Endpoints

### POST /auth/signup
- Description: Register a new user
- Request Body (UserDTO):
  {
    "name": "string (required)",
    "email": "string (required)",
    "whatsapp": "string",
    "passwordHash": "string (required)"
  }
- Response (201 Created):
  {
    "token": "string",
    "type": "Bearer",
    "userId": "UUID",
    "userName": "string",
    "userEmail": "string",
    "profileId": "integer"
  }
- Error (409 Conflict): "Email already registered"

### POST /auth/login
- Description: Login user
- Request Body (LoginRequestDTO):
  {
    "email": "string (required)",
    "password": "string (required)"
  }
- Response (200 OK):
  {
    "token": "string",
    "type": "Bearer",
    "userId": "UUID",
    "userName": "string",
    "userEmail": "string",
    "profileId": "integer"
  }

## User Management

### GET /users?page=0&size=10
- Description: Get paginated list of users
- Response: Page<UserDTO>

### GET /users/{id}
- Description: Get user by ID
- Path Param: id (UUID)
- Response: UserDTO

### POST /users
- Description: Create new user
- Request Body: UserDTO
- Response: UserDTO

### PUT /users/{id}
- Description: Update user
- Path Param: id (UUID)
- Request Body: UserDTO
- Response: UserDTO

### DELETE /users/{id}
- Description: Delete user
- Path Param: id (UUID)
- Response: 204 No Content

## Notes
- All protected routes require Authorization header: Bearer <token>
- Pagination uses ?page=0&size=10
- Dates are in ISO format
- UUIDs for user and movement IDs
- Integers for category, patrimony, profile, type IDs
